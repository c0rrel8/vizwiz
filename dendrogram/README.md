# Dendrogram

A 3-level tree diagram showing hierarchical relationships as branching
paths. **Raw Vega** (`.vg.json`) — the `tree`/`cluster` transforms are
hierarchy layouts with no Vega-Lite equivalent. Provider must be set to
**Vega** before pasting in Deneb.

## Features

- **Layout method**: toggle between `cluster` (all leaves align at the
  same depth — the classic dendrogram) and `tidy` (Reingold-Tilford
  proportional spacing).
- **Orientation**: `vertical` (root top, leaves bottom), `horizontal`
  (root left, leaves right — best for long labels), `radial` (root at
  center, leaves on the perimeter — best for large trees).
- **Branch style**: `stepped` (right-angle elbows / orthogonal),
  `angled` (straight diagonal lines), `spline` (smooth cubic bezier
  curves — the default).
- **Two optional metrics**: Measure A drives node circle size; Measure B
  drives branch stroke width. When either is unbound, the visual falls
  back to fixed sizes (purely structural).
- **Node mark visibility**: `all` (circles at every level), `leaves`
  (Level 3 only), `none` (branches and labels only).
- **Per-level color overrides** via DAX measures, same `isValid()`
  fallback pattern as sunburst and circle packing.
- **Click-to-select** on node circles with ancestor/descendant opacity
  dimming on both nodes and links.
- **Cross-highlighting** via `Measure A__highlight`.

## Fields expected

Bind these in Deneb's data well:

| Role | Field(s) | Required? |
|---|---|---|
| Level 1 category | One of the 4 candidate columns (via `MappedParameter` slicer) | Yes |
| Level 2 category | One of the 4 candidate columns (via `MappedParameterTwo` slicer) | Yes |
| Level 3 category | One of the 4 candidate columns (via `MappedParameterThree` slicer) | Yes |
| Node size metric | `Measure A` | Optional |
| Cross-highlight | `Measure A__highlight` (auto-generated by Deneb) | Optional |
| Branch thickness metric | `Measure B` | Optional |
| Level 1 fill override | `Level1ColorOverrideFill` (DAX measure) | Optional |
| Level 1 stroke override | `Level1ColorOverrideBorder` (DAX measure) | Optional |
| Level 2 fill override | `Level2ColorOverrideFill` | Optional |
| Level 2 stroke override | `Level2ColorOverrideBorder` | Optional |
| Level 3 fill override | `Level3ColorOverrideFill` | Optional |
| Level 3 stroke override | `Level3ColorOverrideBorder` | Optional |

## Field mapping

Same 3-way exclusion cascade as sunburst and circle packing. Each level
picks the first valid candidate column not already claimed by a
higher-priority level. See `patterns.md` for the full pattern.

## Params reference

### Layout

| Param | Type | Default | Description |
|---|---|---|---|
| `layoutMethod` | `"cluster"` / `"tidy"` | `"cluster"` | Cluster aligns all leaves at max depth; tidy uses Reingold-Tilford spacing |
| `orientation` | `"vertical"` / `"horizontal"` / `"radial"` | `"horizontal"` | Tree growth direction |
| `branchStyle` | `"stepped"` / `"angled"` / `"spline"` | `"spline"` | Branch connector shape |
| `layoutPadding` | number | `60` | Pixel padding around the tree area |
| `radialInnerRadius` | number | `30` | Minimum radius from center for radial orientation |

### Nodes

| Param | Type | Default | Description |
|---|---|---|---|
| `nodeMarkMode` | `"all"` / `"leaves"` / `"none"` | `"all"` | Which nodes render circle marks |
| `nodeRadius` | number | `5` | Fixed circle radius (when metric scaling is off) |
| `nodeRadiusMetric` | boolean | `false` | Scale node size by Measure A |
| `nodeSizeMin` | number | `3` | Minimum node radius when metric-scaled |
| `nodeSizeMax` | number | `12` | Maximum node radius when metric-scaled |
| `strokeWidth` | number | `1` | Node circle stroke width |

### Branches

| Param | Type | Default | Description |
|---|---|---|---|
| `branchStrokeWidth` | number | `1.5` | Fixed branch line width |
| `branchStrokeWidthMetric` | boolean | `false` | Scale branch width by Measure B |
| `branchWidthMin` | number | `0.5` | Minimum branch width when metric-scaled |
| `branchWidthMax` | number | `8` | Maximum branch width when metric-scaled |
| `branchStrokeColor` | color | `"#A5B4CB"` | Branch line color |

### Per-level colors (node circles)

| Param | Default | Description |
|---|---|---|
| `level1DefaultFillColor` | `"#2D3B68"` | Level 1 node fill |
| `level2DefaultFillColor` | `"#4555D6"` | Level 2 node fill |
| `level3DefaultFillColor` | `"#8C97E8"` | Level 3 node fill |
| `level1DefaultStrokeColor` | `"#182231"` | Level 1 node stroke |
| `level2DefaultStrokeColor` | `"#182231"` | Level 2 node stroke |
| `level3DefaultStrokeColor` | `"#182231"` | Level 3 node stroke |

### Labels

| Param | Type | Default | Description |
|---|---|---|---|
| `level1ShowLabel` | boolean | `true` | Show Level 1 (branch) labels |
| `level2ShowLabel` | boolean | `false` | Show Level 2 (mid-level) labels |
| `level3ShowLabel` | boolean | `true` | Show Level 3 (leaf) labels |
| `labelFontFamily` | string | `"Segoe UI"` | Font family |
| `labelFontSize` | number (pt) | `11` | Font size in points (converted to px internally) |
| `labelColor` | color | `"#FCFCFD"` | Level 1 label color (title tier) |
| `labelSubtitleColor` | color | `"#A5B4CB"` | Level 2/3 label color (subtitle tier) |

## Setup in Deneb

1. Create a new Deneb visual. **Set Provider to Vega** (not Vega-Lite).
2. Paste `dendrogram.vg.json` into the Specification tab.
3. Leave the Config tab empty (the spec is self-contained).
4. Bind the candidate columns and measures in the data well.
5. Add field parameter slicers for `MappedParameter`,
   `MappedParameterTwo`, and `MappedParameterThree`.

## Design source

The D3.js examples at data-to-viz.com/graph/dendrogram.html were the
primary reference — D3's `d3.tree()` / `d3.cluster()` map directly to
Vega's `tree` transform with the same `method` parameter, and D3's link
generators correspond to Vega's `linkpath` transform shapes.

## Known limitations

- Click-to-select requires node circles (`nodeMarkMode` must not be
  `"none"`).
- Radial orientation with stepped branch style uses Vega's built-in
  `orthogonal` linkpath in polar coordinates — the visual result may
  differ from a pure arc-and-radial-line approach.
- Not yet verified in live Power BI. Deneb's field exposure quirks, real
  report theme integration, and actual Format-pane behavior need the
  report author's own live test to confirm.
- Click-to-filter (Deneb's own Power BI cross-filter integration) is
  presumed functional but not tested.
- Pipe-separated multi-value fields in candidate columns are untested.
